# Data — 仿真数据归档（按"一次运行一个文件夹"）

这里存放 LTspice 跑出来并经过分析的成果。**上游仿真文件仍在 `ltspice/` 里（decks / models / inc），
本目录只放结果**，目的是让后续每一次新的扫描/分析都在自己的文件夹里，互不覆盖、互不混淆。

## 命名规范

```
Data/
└── <日期>_<主题>_<工况>[_<内容>]/          例：2026-09-22_BONE_8V100uA_Req_analysis
    ├── README.md                           本次运行：条件 / 结论 / 文件清单 / QA 记录
    ├── <同名>.xlsx                          数据表（多工作表：说明 + 各数据集）
    ├── plot_<同名>.py                       绘图脚本（含图契约，可一键复现）
    ├── charts/
    │   ├── Fig1_<同名>.png / .pdf / .svg / .tiff     图（PNG 供阅读，PDF/SVG 可编辑，TIFF 投稿栅格）
    │   └── qa/                              QA 产物：*.alignment.json/.svg、*.collision-audit.json
    └── data/
        └── <数据集>_<区分条件>.csv           原始数据（SI 单位），文件名写清条件
```

约定：

- **日期在前**（`YYYY-MM-DD`），便于按时间排序；**主题/工况写清电路与工作点**（如 `BONE_8V100uA`），
  避免 "data1/新建文件夹" 这类无法检索的名字。
- 一次运行一个文件夹：换了扫描范围、换了工作点、换了负载，就**新建一个文件夹**，不要在旧文件夹里追加。
- 文件夹名 = 内部主文件名的前缀，`grep`/`ls` 天然对应。
- 图统一放 `charts/`，图内的英文小图另存 PNG；只有一张主图时命名 `Fig1_<同名>.png`，
  多图时按 `Fig2_`、`Fig3_` 递增。
- `charts/qa/` 里的对齐/碰撞审计文件是**质量证据**，随图一起保留（不是图的替代品）。
- CSV 一律 SI 单位（A / V / Ω / W），Excel 表可用工程单位（µA / kΩ / µW），两者都要能对应上。

五个工况构成完整对比链：8 V / 5 V 两个母线点各自扫骨阻；8 V 下扫设定值；再固定 10 kΩ 与 30 kΩ
各铺一遍"母线 × 设定值"网格（后者同时验证不变性并逼出边界）。**母线电压只决定"能驱动多大骨阻"
与端口等效电阻；设定值决定刺激电流，并决定电路自身偏置占母线电流的比例；骨阻只要不越过该档
顺从上限，就对端口等效负载完全没有影响。** 五张图均为 183.0 × 118.0 mm、同一套 4 面板布局，
可直接并排使用。

## 与工程其余部分的关系

| 位置 | 作用 |
|---|---|
| `ltspice/*.asc` | 原理图（仿真入口） |
| `ltspice/decks/*.cir` | 网表形式的仿真 deck |
| `ltspice/summary.txt` | 最近一次完整验证（`tools/run_all.py`）的输出留档 |
| `ltspice/Data/`（本目录） | 归档的结果数据与图，按运行分文件夹 |
| `self/simulink/` | 给 Simulink 用的等效负载模型（公式 + CSV） |
| `仿真结论_2026-09-21.md` | 整个项目的结论报告（含可信度分级与未覆盖边界） |
