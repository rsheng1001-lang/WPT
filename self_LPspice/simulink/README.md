# VBUS 端口等效负载（供 Simulink 用）—— 含骨负载依赖

整流输出 VBUS **往右的整块电路**（8V LDO → 3.3V LDO → 恒流沉 → 骨负载）当作一个
二端负载时的准静态模型，跟整流器/无线供电模型对接。

## 模型

```
V_BONE_P = min(V_bus, 8.0016)                8V LDO（母线低时 dropout 直通）
V_3V3    = min(V_BONE_P, 3.3)                3.3V LDO（同理）

I_bone   = min( I_set , I_limit )
  I_set   = V_3V3/(11*R10) - 218 nA          设定电流：比例于 3.3V 轨；218 nA 是 R9 误差
  I_limit = V_BONE_P/(R_bone + R10)          顺从区外 FET 全开，只剩纯电阻通路

I_bus    = I_bone + min(V_bus,8.0016)/666.8k + V_3V3/110k + 23.03 uA
```

| 参数 | 值 | 来源 |
|---|---|---|
| `8.0016 V` | 8V LDO 输出 | ST715 分压设定（560k/6.8k/100k） |
| `R10` | 3 kΩ | 采样电阻，`I = V(I_SENSE)/R10` |
| `218 nA` | R9 = 10 MΩ 从栅极节点（≈2.48 V）灌进采样节点的电流 | 实测 `I(R10) − I(R_bone) = 217.9 nA`，与 `(2.480−0.300)/10M = 218.0 nA` 吻合 |
| `666.8 kΩ` | R1+R2+R3（8V LDO 反馈分压串） | LDO 未稳压时直接挂在母线上，构成 dropout 区斜率 |
| `110 kΩ` | R5+R7（3.3V 轨上的基准分压） | 30 µA 固定负载 |
| `23.03 µA` | U1/U2/U3 三颗器件静态电流 | 由实测电流收支反推 |

**标定与验证**（LTspice，母线 4→16 V 连续扫描 + 骨阻 16 点瞬态表）：

| 对照 | 最大相对误差 |
|---|---|
| 母线曲线（R_bone = 10 kΩ，636 点，V ≥ 3.3 V） | **0.0075 %** |
| 两端电流表（16 点，含 8 V / 3.3 V 母线的顺从拐点） | I_bus 0.051 %，I_bone 0.064 % |

## 什么会影响这个等效负载

| 影响因素 | 影响哪一项 | 量级与实测证据 |
|---|---|---|
| **骨负载 R_bone** | 只在**顶出顺从区**时影响 I_bus | 顺从区内 I_bus 与骨阻**完全无关**：8 V 母线、10k→76k，实测 164.801 µA 六位数字不变。越限后 I_bus 与 I_bone **一比一同步下降**（差值恒为 65.0 µA，超限后仅漂 0.09 µA） |
| **母线电压 V_bus** | 模型里的 `min()`；8 V 以下按 666.8 kΩ 上升；3.3 V 以下再叠一层 | 见下表。8.4 V 以上几乎无影响（8 V vs 12 V 仅差 14 nA） |
| **3.3 V 轨电压** | 设定电流 `I_set`，**比例式** | I_set = V_3V3/(11·R10)：1% 轨误差 = 1% 电流误差。实测母线 3.0 V（轨 2.999 V）时 I_bone = 90.66 µA = 99.78 × 2.999/3.3 |
| **R10（3 kΩ）** | `I_set`，比例式 | 1% 容差 → 1% 电流误差（直接传递，未经反馈校正） |
| **R5/R7 分压比** | `I_set` 的分子 | R5=100k / R7=10k 决定 0.3 V 基准；两者容差同样比例传递 |
| **R9 = 10 MΩ** | 固定 −218 nA（−0.22%） | 骨端恒比采样值低 0.22%；该项随 Vgs（即 Vth、温度）变，Vth 高时误差更大 |
| **R1+R2+R3 = 666.8 kΩ** | dropout 区斜率（等效并联电阻） | 拟合值 666.53 kΩ，与标称和差 0.04% |
| **3.3 V 轨上的固定负载** | 只加在 I_bus 上（R5/R7 的 30 µA + 静态 23 µA） | 这是 I_bus 里"与骨端无关"的 ~58–65 µA 偏置 |
| **温度 / Vth 离散** | 环路余量与 R9 误差项 | 见 `ltspice/summary.txt` 第 8 节：轨 3.2 V 下 Vth 从 2.5 V 走到 3.0 V，电流从 96.97 µA 掉到 50.5 µA（环路余量耗尽） |
| ~~母线 8.4 V 以上时 V_bus 的高低~~ | 基本无影响 | 12 V 母线（164.815 µA）vs 8 V（164.801 µA），差 14 nA |

## 在 Simulink 里接线

`Controlled Current Source`（VBUS → 地），控制端接 `MATLAB Function` 块调用
`bus_load_current(u(1), u(2))`（母线电压、骨阻两个输入），VBUS 对地并 **1.1 µF**
（C5 1µ + C6 100n，唯一的动态元件）。

- 不想用 MATLAB Function 块：`Gain(1/666.8e3)` → `Sum(+23.03e-6 + V_3V3/110k)` → 与
  `min(...)` 分支相加，需要两个 `Min` 块（一个管 LDO dropout，一个管顺从越限）。
- 骨阻固定在顺从区内时，可退化成单输入版：`I = min(164.81 µA, 152.80 µA + V/666.5 kΩ)`。
- 母线始终 8.4 V 以上时最简：**164.8 µA 恒流源 + 1.1 µF**（误差 ≤0.01%）。

动态上不必额外做什么：无启动过冲（3.3 V 轨起来前栅极不驱动），负载阶跃 37 µs 内回到 ±2%，
所以 kHz 以上仿真里"准静态 + 1.1 µF"够用。

## 数据来源与验证状态

- 母线曲线：`decks/full_bus_dc.cir` 同一网表，`.dc` 改成 16 → 0 V / 0.02 V 步长 / `numdgt=15`，
  从高往低连续求解保证全程在物理解上。
- 两端电流表：固定母线 + `.tran 30m startup` + `.meas`（27–30 ms 平均）。用瞬态而不是冷
  `.op`，是因为顺从区外 OPAx333 宏模型有竞争解（见 `decks/core_op.cir` 的说明），
  启动瞬态总能落到物理解上。
- 模型数值已用上述两组数据在 Python 里逐点核对（误差见上表），临时探测 deck 已删除，
  `ltspice/` 目录只留原有文件。
- **`bus_load_current.m` 的算式在 Python 里等价核对过，但本机 MATLAB 会话当时连不上，
  没能在 MATLAB 里实跑**。第一次用请先 `bus_load_current(12, 10e3)` 自检：应得
  `1.648e-04` 与 `9.978e-05`。

## 三条限制

1. **8V/3.3V 两颗 LDO 与 TVS 是自制近似模型**：直流电流收支可信，但 LDO 的 dropout
   精确位置、稳定性、保护行为不可信。尤其真实 MCP1703A 在 3.3 V 输入时已进 dropout，
   所以 V_bus 略高于 3.3 V 时，实际电流会比模型低（模型在这段给的是乐观值）。
2. **只标定在标称元件值**，没做 corner：1% 电阻容差、Vth 离散、温度都按标称值。
   比例式的项（R10、R5/R7、3.3 V 轨）误差是直接 1:1 传递的，设计时按此留余量。
3. **R_bone = 10 kΩ 是测试电阻**，不是实测骨阻抗；真实电极是容性阻抗，
   脉冲边沿行为本模型不覆盖（只覆盖准静态 I-V）。
